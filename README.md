# Thermal-Aware Power Budgeting for a Quad-Core RISC-V Processor

## 1. Project Overview

This capstone project investigates thermal-aware power budgeting in a quad-core RISC-V processor using mathematical modelling, numerical methods, and optimization techniques.

The project aims to study the relationship between power distribution and chip temperature and explore how optimization can help reduce peak temperature while satisfying power constraints.

## 2. Problem Statement

Uneven power distribution in a processor can lead to localized hotspots, affecting performance, reliability, and energy efficiency. This project formulates a mathematical approach to analyzing chip temperature and optimizing power allocation.

## 3. Objectives

- Model heat distribution across a processor chip.
- Apply partial differential equations to represent thermal behaviour.
- Use numerical methods to approximate the temperature distribution.
- Formulate an optimization problem for power budgeting.
- Investigate strategies to minimize peak chip temperature under power constraints.

## 4. Methodology

The project follows a mathematical pipeline consisting of:

1. **Thermal Modelling:** Represent heat transfer using Fourier's law and a heat equation.
2. **Mathematical Analysis:** Apply the mathematical techniques described in the project report.
3. **Numerical Discretization:** Approximate the temperature field using a spatial grid.
4. **Optimization:** Formulate a power-allocation problem to reduce peak temperature.
5. **Evaluation:** Analyze the results using the selected model, constraints, and performance measures.
